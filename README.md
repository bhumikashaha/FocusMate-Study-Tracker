**📚 FocusMate – Study Tracker**

🎯 Smart Study Planning & Productivity Management System

**🚀 Project Overview**

FocusMate is a web-based study tracking application designed to help students manage their study time, track daily progress, and improve productivity.

It allows users to set study goals, monitor completed tasks, and stay consistent with their learning schedule.

🌟 Key Features

⏳ Study Session Tracker

• Track daily study hours • Monitor subject-wise progress • Maintain study consistency

📝 Task Management

• Add, update, and delete study tasks • Set daily or weekly goals • Track completed and pending tasks

📊 Progress Monitoring

• View overall study performance • Track productivity trends • Stay motivated with progress insights

👤 User Management

• Secure login & registration • Personalized dashboard • Individual study records
